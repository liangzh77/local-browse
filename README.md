# LocalBrowse 本地文件浏览器

LocalBrowse 是一个轻量级本地文件浏览工具。它会在本机启动一个临时 HTTP 服务，并自动打开浏览器，让你用网页界面浏览本地文件夹中的 Markdown、代码、文本、图片、SVG 和 HTML 文件。

这个项目可以独立使用，不依赖其他工程。Windows 用户可以直接双击 `start.bat` 启动。

## 功能特点

- 本地运行：服务只绑定 `127.0.0.1`，用于本机访问。
- 自动打开浏览器：启动后自动打开 `http://127.0.0.1:<端口>`。
- 自动选择端口：由系统分配可用端口，减少端口冲突。
- 文件树浏览：左侧展示当前根目录下可浏览的目录和文件。
- 切换浏览目录：点击顶部 `打开文件夹`，可以选择新的本地目录。
- 刷新文件树：点击刷新按钮可重新读取当前目录。
- 明暗主题：支持浅色和深色界面切换。
- Markdown 预览：`.md` 文件会渲染为文档页面。
- 代码高亮：常见源代码文件会使用语法高亮显示。
- 图片预览：支持 `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`。
- SVG 预览：支持直接查看 `.svg` 文件。
- HTML 预览：`.html` 文件会在页面内通过 iframe 打开。
- 文本查看：支持 `.txt`、`.csv`、`.json`、`.yaml` 等文本类文件。

## 环境要求

- Python 3.9 或更高版本
- Windows 下推荐使用 `start.bat`

## 快速开始

双击运行：

```bat
start.bat
```

也可以在命令行中运行：

```bat
cd C:\liangz77\python_projects\github_projects\local-browse
start.bat
```

指定初始浏览目录：

```bat
start.bat C:\path\to\folder
```

如果不指定目录，默认浏览 LocalBrowse 自身所在文件夹。

## 文件说明

- `start.bat`：Windows 启动脚本，负责检查 Python、切换到项目目录并运行服务器。
- `server.py`：本地 HTTP 服务，负责生成文件树、读取文件内容、切换浏览根目录并提供接口。
- `index.html`：浏览器界面，负责显示文件树、渲染 Markdown、代码、图片、SVG、HTML 和文本。
- `README.md`：项目说明文档。

## 可见性规则

LocalBrowse 不会展示所有文件。它会隐藏一些不适合浏览或容易产生大量内容的目录，例如：

- `.git`
- `.claude`
- `__pycache__`
- `node_modules`
- `.vscode`
- `.idea`

默认也会隐藏大部分点号开头的目录，但保留 `.memory`。可浏览的文件类型由 `server.py` 中的扩展名白名单控制。

## 安全说明

LocalBrowse 是只读文件浏览器，不提供编辑、删除或上传功能。

服务器只绑定到本机地址 `127.0.0.1`。切换浏览目录后，后端会校验请求路径，确保只能读取当前根目录内部的文件，避免通过路径跳转访问根目录之外的内容。

## 常见问题

### 启动后没有自动打开浏览器怎么办？

查看命令行窗口中的地址，例如：

```text
LocalBrowse -> http://127.0.0.1:54321
```

把这个地址复制到浏览器中打开即可。

### 为什么有些文件没有显示？

LocalBrowse 只显示常见文本、代码、图片和 SVG 文件。二进制文件、缓存目录、依赖目录和大部分隐藏目录会被过滤。

### 如何停止服务？

在启动服务的命令行窗口中按 `Ctrl+C`，或者直接关闭该窗口。
